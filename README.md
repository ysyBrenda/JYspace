# JYspace
private space

GitHub Pages site.

Structure:
- `index.html` Firebase Auth login
- `app.html` main page
- `messages.html` messages full page
- `assets/css/index.css` index styles
- `assets/css/app.css` app styles
- `assets/js/index.js` index logic
- `assets/js/firebase.js` Firebase init (exports `window.db`)
- `assets/js/app.js` app logic (messages + timeline)
- `assets/js/messages.js` messages page logic

use firebase：
https://console.firebase.google.com/
